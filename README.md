# cookie-frontend

The user-facing half of Cookie: what runs on your own computer.

Today that is **`cookie-interface`** — the microphone, the voice, and the orb
beside your cursor. It contains no model, no agent and no reasoning; the mind
lives in [cookie-backend](https://github.com/microserv-net/cookie-backend) and
is reached over the protocol in `docs/backend.md`.

See [cookie-interface/README.md](cookie-interface/README.md).
